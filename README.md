# FlappyBirdieUnity

A simple 2D arcade game inspired by side-scrolling obstacle games, built with Unity and C#.

Overview

Control a flying character and navigate through obstacles. Time each movement carefully to avoid collisions and achieve a high score.

Features

Player flight controls

Gravity-based movement

Obstacle spawning

Collision detection

Score tracking

Game over mechanics

Built With

Engine: Unity

Language: C#

Version Control: Git and GitHub

Getting Started

Clone or download this repository.

Open Unity Hub.

Select Add Project from Disk and choose the project folder.

Open the project using a compatible Unity version.

Open the main scene and press Play.

Project Structure

Assets/ — Game assets, scripts, and scenes

Packages/ — Unity package dependencies

ProjectSettings/ — Unity project configuration
